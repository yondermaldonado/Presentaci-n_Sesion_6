# 🎨 Landing Curso Web — Sesión 6: Unidades CSS, Display y Flexbox

Landing page de práctica para la **Sesión 6 de CSS**, enfocada en unidades relativas (`px`, `%`, `rem`, `vw`, `vh`), las propiedades `display` (block, inline, inline-block, flex) y **Flexbox** para maquetación flexible.

Proyecto desarrollado con **HTML5 y CSS3** puro, sin frameworks ni JavaScript.

## ✨ Características

- **Barra de navegación** fija (`sticky`) con logo y enlaces internos a las secciones de la página.
- **Sección de inicio (hero)**: título, descripción y botón de llamada a la acción, maquetados con Flexbox y unidades relativas (`vh`, `vw`).
- **Sección de habilidades**: tarjetas que resumen los temas de la sesión (Unidades CSS, Display, Flexbox).
- **Sección de perfil del estudiante**: imagen de avatar junto a una descripción, organizada en fila con Flexbox.
- **Sección de etiquetas (tags)**: lista de tecnologías/temas trabajados (HTML, CSS, Flexbox, Responsive, Maquetación).
- **Pie de página** con el nombre de la sesión.

> ⚠️ Nota: `index.html` incluye una segunda hoja de estilos, `css/styles-inicial.css`, que no está presente en el proyecto. Puede eliminarse la referencia en el `<head>` o agregar el archivo si existía como punto de partida del ejercicio.

## 🛠️ Tecnologías utilizadas

- **HTML5** — estructura semántica de la landing page.
- **CSS3**:
  - Unidades relativas: `rem`, `%`, `vw`, `vh`.
  - Propiedades `display`: `flex`, `block`, `inline-block`.
  - **Flexbox** para la barra de navegación, el hero y la fila de perfil.
  - Posicionamiento (`position: sticky`) para la barra de navegación.

## 📁 Estructura del proyecto

```
Presentacion_Sesion_6-main/
├── index.html            # Landing page
├── css/
│   └── styles.css        # Estilos: unidades, display y Flexbox
└── assets/
    └── yonder.jpeg        # Imagen de perfil del estudiante
```

## 🚀 Instalación y ejecución

Este proyecto es un archivo estático simple, no requiere backend ni instalación de dependencias.

1. Clona el repositorio:
   ```bash
   git clone https://github.com/yondermaldonado/Presentacion_Sesion_6.git
   cd Presentacion_Sesion_6
   ```

2. Abre `index.html` directamente en tu navegador.

3. Navega usando el menú superior: Inicio, Habilidades y Perfil.
